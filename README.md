## Search visibility

The first target is **Blue Agave Rossland menu**, followed by **Mexican restaurant Rossland**. The site puts verified menu highlights and visit details in HTML, assigns each page its own canonical URL, and includes an XML sitemap.

For Google, the URL-prefix property is \`https://xsploit.github.io/blue-agave-rossland/\`. Once the property is verified, submit \`sitemap.xml\` in Search Console and check indexing and the branded query. Google's AI search features use the same SEO fundamentals. For ChatGPT Search, check access for OAI-SearchBot at the GitHub Pages host and whether answers to the target queries cite the menu page.
